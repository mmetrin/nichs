# МТС Маркетолог 2.0

Самостоятельный React/Vite-проект страницы `/platform-core/`, выделенный из `mmetrin/test-oct` (исходный коммит `61a5c0039976ec639ae37a61329f5c4e5fa7056f`). В репозитории только код этой страницы, её графика, шрифты, видео, используемые общие компоненты и проверки.

## Запуск

Нужен Node.js 22.12+ или 24 LTS.

```sh
npm ci
npm run dev
```

Откройте адрес из терминала. Одна и та же страница доступна в корне `/` и по исходному пути `/platform-core/`. Если порт 5173 занят, Vite выберет следующий свободный.

```sh
npm run lint
npm test
npm run build
npm run preview
```

`npm run build:pages` собирает сайт с базовым путём `/nichs/` для GitHub Pages. Эта команда только создаёт `dist/`, не публикует сайт.

## Публикация

Адрес после включения GitHub Pages: https://mmetrin.github.io/nichs/ — исходный путь `/nichs/platform-core/` также поддерживается.

После включения Pages GitHub Actions автоматически проверяет, собирает и публикует страницу после каждого push в `main`. Workflow: `.github/workflows/pages.yml`; его также можно запустить вручную через Actions → Publish GitHub Pages → Run workflow. В настройках репозитория Pages нужно выбрать источник **GitHub Actions**. Сборка передаётся как артефакт, поэтому `dist/` не хранится в Git.

## Индексация

В обеих HTML-точках входа установлен `<meta name="robots" content="noindex, nofollow">`. Перед публикацией `scripts/check-noindex.mjs` проверяет все HTML-файлы в `dist` и останавливает workflow, если запрет удалён. Не убирайте его без отдельного решения включить индексацию.

Запрет применяется к странице сайта, а не к публичному репозиторию GitHub. Он не ограничивает доступ по прямой ссылке. `robots.txt` с `Disallow` не добавляется: поисковику нужно прочитать HTML, чтобы увидеть `noindex` ([документация Google](https://developers.google.com/search/docs/crawling-indexing/block-indexing)).

## Где что лежит

- `src/platform-core-main.jsx` — запуск страницы с общим `DesignViewport`.
- `src/pages/platform-core/` — композиция страницы и меню переходов к блокам.
- `src/features/platform-core/` — первый экран, 3D-сцена, аудитория, площадки, калькулятор, видео и FAQ.
- `src/shared/ui/design-viewport/` — общий скейл из исходного сайта; подробнее в [правилах адаптации](docs/adaptation.md).
- `src/shared/ui/` — шапка, подвал, фоновые частицы и нужные стили кнопок.
- `src/shared/styles/tokens.css` — цвета и дизайн-токены страницы.
- `src/assets/` — используемые изображения, SVG, портреты, шрифты и три видео с обложками. Часть папок сохраняет названия исходных наборов графики, но исходников других страниц здесь нет.

В репозиторий не входят `node_modules`, `dist`, скриншоты проверок, промежуточные экспорты, исходные видеозаписи и остальные страницы сайта.

## Поведение исходного макета

Навигация шапки ведёт к блокам этой страницы. Кнопки заявки ведут к блоку `#connection`. Форма в этом блоке, как в исходнике, является изображением: серверной отправки заявки нет. Калькулятор даёт предварительную оценку по перенесённым данным, а не коммерческое предложение.

Ссылки подвала на другие разделы ведут на исходный сайт `https://mmetrin.github.io/test-oct/`; эти разделы не копируются в репозиторий. Ссылки, у которых в исходнике не было адресов, остаются текстом.
