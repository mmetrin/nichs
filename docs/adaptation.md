# Правила адаптации и скейла

Используется тот же `DesignViewport`, что на страницах DSP, Smart TV, сертификации, контактов и других страницах исходного проекта.

## Размер макета и порог

Ширина рабочего макета — **1920 px**. Порог масштабирования — **1600 px**. Это разные значения; не заменяйте порог на 1920, если нужно сохранить поведение исходного сайта.

```js
scale = Math.min(1, window.innerWidth / 1600)
```

| Ширина окна | Масштаб |
| --- | --- |
| 1920 px и больше | 1 |
| 1600 px | 1 |
| 1440 px | 0.9 |
| 1280 px | 0.8 |
| 1024 px | 0.64 |
| 768 px | 0.48 |
| 390 px | 0.24375 |

При ширине 1600 px и больше макет не увеличивается. Ниже 1600 px пропорционально уменьшается вся композиция, включая текст, отступы, изображения, видео, калькулятор и шапку. При изменении окна масштаб пересчитывается.

## Как это устроено

- `src/shared/ui/design-viewport/designScale.js` — константа `SCALE_THRESHOLD = 1600` и формула.
- `DesignViewport.jsx` — устанавливает CSS `zoom` и переменную `--design-scale`; фиксирует медиазапросы по ширине в px и единицы `vw` относительно макета 1920 px, включая стили, добавленные при HMR.
- `DesignViewport.css` — фиксирует ширину макета и синхронизирует масштаб шапки, которая рендерится порталом в `body`.
- `src/features/platform-core/useCoreMotion.js` — сохраняет десктопную 3D-композицию на всех ширинах. Уменьшение окна меняет масштаб, а не число модулей, освещение или анимацию стыковки.

Страница центрируется. Как и в исходном механизме, при некоторых ширинах края рабочего холста 1920 px выходят за окно и обрезаются: это не схема «вписать весь холст по ширине». Основной контент расположен внутри центральной области 1440 px. Горизонтальная прокрутка отключена.

Мобильная перевёрстка не включается: узкий экран показывает уменьшенную десктопную композицию. Это буквальное применение общих правил исходного сайта, включая очень мелкий текст на телефоне.

## Правила для дальнейших изменений

1. Меняйте порог в `designScale.js`; при изменении ширины самого макета синхронно меняйте `DESIGN_WIDTH` в компоненте и значения 1920 px в CSS.
2. Оставляйте всю страницу внутри одного `DesignViewport`. Не добавляйте второй скейл к отдельным секциям. Существующий `100cqw / 1920px` внутри блоков равен 1 при рабочей ширине 1920 px.
3. Не привязывайте выбор 3D-композиции к реальной ширине окна: она должна соответствовать фиксированному макету.
4. Сохраняйте `prefers-reduced-motion`, остановку анимаций вне экрана и при скрытой вкладке. Они не зависят от порога скейла.
5. Проверяйте как минимум 1920, 1600, 1599, 1440, 1280 и 390 px, а также изменение ширины без перезагрузки. Шапка и контент должны иметь одинаковый масштаб; внутренние блоки не должны масштабироваться повторно.

Самостоятельный механизм мобильной адаптации потребует отдельного изменения этих правил.
